順手修掉的兩個 shell 坑（都不是工具壞了）

批次腳本第一次跑的時候看起來像「全部跳過」，其實是兩個 shell 行為：

  1. 先 cd 再用 $(dirname "$0") 會以新的工作目錄解析相對路徑 → 找不到清單檔， 而且 exit code 還是 0，背景任務回報「完成」。
  2. macOS 是 bash 3.2，在 set -u 之下展開空陣列會噴 unbound variable 直接中斷（新版 bash 不會）。要寫 ${args[@]+"${args[@]}"}。

兩個都修掉了，腳本現在失敗會反映在 exit code 上。 （另外 zsh 不做未加引號的斷詞這件事，這一輪踩了三次——--image、--frames 都中過，這是既有 skill 文件裡就記過的坑。）
